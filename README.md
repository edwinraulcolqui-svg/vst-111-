# DeliriumT Vocals — Dark Grave / DXTXM

**Target:** Windows 10/11 x64 · FL Studio · VST3  
**Version:** 1.0.0

A six-module vocal effect processor designed for Darkwave, Gothic Post-Punk, Deathrock and adjacent dark electronic styles.

## Included Modules
1. **EQ**: Low Shelf (200Hz), Sweepable Mid Parametric (200Hz - 6kHz), High Shelf (5kHz)
2. **Compressor**: Threshold (-60 to 0dB), Ratio (1:1 to 20:1), Attack, Release, Makeup Gain
3. **Chorus**: Rate, Depth, Wet/Dry Mix
4. **Stereo Delay**: Time, Feedback, Stereo Channel Offset, Wet/Dry Mix
5. **Reverb**: Decay, Room Size, High Frequency Damping, Pre-delay, Wet/Dry Mix
6. **Saturation**: Soft-clipping Drive, Tone cutoff, Wet/Dry Mix

## How to Compile
- **Automated (Free via GitHub Actions)**: Push to GitHub, go to Actions -> Build DeliriumT Vocals -> Download the compiled Setup.exe and VST3 artifact.
- **Local Windows**: Open Developer PowerShell / cmd in project root and run `BUILD_WINDOWS.bat`.
